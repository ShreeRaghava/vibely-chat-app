IF CONNECTION FAILS
================================================================================

Check console for errors:
- "PeerJS connection failed" → Network issue
- "Peer ID publish error" → Server issue
- "Stream not ready" → Permission issue
- "Remote peer not found" → Room issue

Try:
1. Both on same WiFi
2. Try different browser
3. Try different room ID
4. Clear browser cache (Ctrl+Shift+Delete)
5. Hard refresh (Ctrl+Shift+R)

If still failing: Share console output with me
