                       📞 TROUBLESHOOTING QUICK GUIDE
================================================================================

Q: "Searching for a match..." still shows forever
A: 
  - Check if Vercel deployed (refresh)
  - Clear browser cache (Ctrl+Shift+Delete)
  - Hard refresh (Ctrl+Shift+R)
  - Try different browser (Chrome/Firefox/Safari)
  - Wait 60 seconds (should auto-redirect now)

Q: Video doesn't connect even after match
A:
  - Check permissions granted (browser settings)
  - Check camera/microphone working
  - Try both on same WiFi first
  - Open console (F12) watch for errors
  - If error shown: note the exact error message

Q: Chat works but video call button missing
A:
  - Page might be loading from cache
  - Hard refresh (Ctrl+Shift+R)
  - Clear cache completely
  - Try different browser

Q: Match works but can't find other person's messages
A:
  - Refresh page (F5)
  - Wait 5 seconds (polling updates every 2.5s)
  - Check if other person in same room
  - Open console, check for errors
